ℹ Control Guide (what each control does — click to collapse)
Simulation
⏸ Pause / Resume
Purpose
Pause or resume the simulation clock.
Why
Freeze the scene to inspect a moment in detail.
How
Toggles the global simulation tick on the backend.
⟲ Reset
Purpose
Restart the simulation from its initial state.
Why
Quickly return to a clean baseline for a new run.
How
Reinitializes vehicle positions, fog levels, and events.
Speed (0.5x – 4x)
Purpose
Change how fast simulated time passes.
Why
Speed up to see long-term patterns, slow down to study detail.
How
Scales the interval between simulation ticks.
▶ Demo Mode
Purpose
Run a scripted end-to-end demo scenario.
Why
Showcase the system's capabilities automatically.
How
Steps through predefined events with on-screen captions.
Fog
Fog: Clear / Light / Medium / Heavy / Extreme
Purpose
Manually set the global fog/visibility level.
Why
Test how the system reacts to different visibility conditions.
How
Overrides the visibility value used by every fog zone.
Auto-Fog
Purpose
Let fog levels change automatically over time.
Why
Simulates realistic, shifting weather without manual input.
How
Cycles the visibility value on a timer when enabled.
Network
GPS-Denied
Purpose
Simulate loss of GPS signal for all vehicles.
Why
Demonstrates dead-reckoning fallback in GPS-denied pits.
How
Forces positioning to use IMU + wheel odometry instead of RTK-GNSS.
V2X
Purpose
Toggle the V2X communication network.
Why
Shows how vehicles behave without V2V/V2I/V2C connectivity.
How
Disables message exchange between vehicles, infrastructure, and control centre.
Links
Purpose
Show or hide communication link lines on the map.
Why
Reduces visual clutter when you only want to see vehicles.
How
Toggles rendering of the connection overlay on the digital twin canvas.
Selection
Select Dumper
Purpose
Choose which dumper truck to inspect.
Why
Quickly focus a specific vehicle without hunting for it on the map.
How
Highlights the chosen truck on the digital twin and loads its detail panels.
Views
🚚 Driver View
Purpose
Open the driver-facing display in a new tab.
Why
See exactly what the truck driver sees and hears.
How
Loads /driver with live telemetry for the selected vehicle.
